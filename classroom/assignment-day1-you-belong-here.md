# Assignment 1: You Belong Here

Welcome to Git Going with GitHub! Today you will learn how real open source teams collaborate -- and you will do it by contributing to a real repository.

## What You Will Do Today

By the end of Day 1, you will have:

- Navigated a GitHub repository and found key files
- Filed an issue describing something you noticed
- Had a conversation using @mentions and comments
- Created a branch, made an edit, and committed it
- Opened a pull request that links to your issue
- Resolved a merge conflict
- Reflected on open source culture and communication
- Merged your work into the main branch

Complete these challenges in order. Each one builds on the previous.

## Evidence

Each challenge has an issue template in the Learning Room. Open the matching issue, complete the challenge, and post your evidence as described in the issue.

## If You Get Stuck

Every chapter has an "If You Get Stuck" section with specific troubleshooting steps. Start there.

If you are still stuck after trying those steps:

1. Ask your buddy (the person sitting next to you)
2. Post a comment on your challenge issue describing what you tried
3. Ask a facilitator -- they will help unblock you, not do the work for you

## Accessibility

This workshop is designed to work with screen readers, keyboard navigation, and other assistive technologies. If you encounter an accessibility barrier, file it as an issue using the Accessibility Report template.

## Buddy System

You have been paired with a classmate. Check in with each other at each challenge. Helping someone else is one of the best ways to solidify your own understanding.
