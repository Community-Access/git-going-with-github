# Challenge Reference Solutions

This directory contains reference solutions for every challenge. They are intended for facilitator use and for learners who get stuck after trying on their own.

## How to use these solutions

- Attempt every challenge first. The struggle is where the learning happens.
- If you are stuck after a real try, peek at the relevant solution and then go back to the challenge.
- Facilitators can use these to confirm acceptance criteria during the workshop.
