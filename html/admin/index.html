Typical Workflow

Planning Phase (Weeks 1-2 Before)

  1. COHORT_PROVISIONING.md - Set up the cohort
  2. FACILITATOR_GUIDE.md - GitHub Classroom setup
  3. ANNOUNCEMENT.md - Create student announcements
  4. STUDENT_MANAGEMENT.md - Prepare roster

Pre-Workshop (48 Hours Before)

  1. FACILITATOR_GUIDE.md - Complete checklist
  2. ACCESSIBILITY_TESTING.md - Test with screen readers
  3. FACILITATOR_OPERATIONS.md - Setup workstation

During Workshop

  1. FACILITATOR_OPERATIONS.md - Follow hour-by-hour procedures
  2. FACILITATOR_CLASSROOM_TROUBLESHOOTING.md - Reference when needed
  3. PROGRESS_TRACKER.md - Track student progress

Post-Workshop

  1. FACILITATOR_GUIDE.md - Follow-up tasks
  2. Update this documentation with lessons learned

Reading Order Recommendations

For First-Time Facilitators

  1. Start: FACILITATOR_RESOURCES.md
  2. Then: FACILITATOR_GUIDE.md (full read)
  3. Then: FACILITATOR_OPERATIONS.md (full read)
  4. Reference: FACILITATOR_CLASSROOM_TROUBLESHOOTING.md

For Returning Facilitators

  1. Quick reference: QUICK_REFERENCE.md
  2. Review: FACILITATOR_GUIDE.md checklist
  3. Keep open: FACILITATOR_OPERATIONS.md during workshop

For Admin/Coordinators

  1. COHORT_PROVISIONING.md - Setup cohorts
  2. STUDENT_MANAGEMENT.md - Manage rosters
  3. PROGRESS_TRACKER.md - Monitor progress
  4. ACCESSIBILITY_TESTING.md - Ensure quality
