VibeVoice Voice Comparison Setup

Tools for evaluating and comparing Microsoft VibeVoice-Realtime-0.5B voices before choosing one for your project.

License: Research/development use only (MIT). Not for commercial production. Every generated audio file includes an audible "This segment was generated by AI" disclaimer embedded automatically by the model.

Hear samples right now -- no install required

Option URL Notes
HuggingFace Space https://huggingface.co/spaces/anycoderapps/VibeVoice-Realtime-0.5B Free, browser-based, pick voice and enter text
Project demo page https://microsoft.github.io/VibeVoice/ Pre-rendered podcast-length audio with named speakers
Google Colab https://colab.research.google.com/github/microsoft/VibeVoice/blob/main/demo/vibevoice_realtime_colab.ipynb Free GPU via Colab, full control

Available built-in English voices

These ship with the repo -- no extra downloads needed.

Voice key Gender Character
en-Carter_man Male Neutral American, clear diction
en-Davis_man Male Warm American, slightly slower cadence
en-Emma_woman Female Clear American, professional tone
en-Frank_man Male Deeper resonance, authoritative
en-Grace_woman Female Softer delivery, friendly

in-Samuel_man Male Indian-English accent, distinct character

Experimental voice packs (run demo/download_experimental_voices.sh)

After downloading, 11 additional English style variants are available plus voices for German, French, Italian, Japanese, Korean, Dutch, Polish, Portuguese, and Spanish.

Local setup (Windows, NVIDIA GPU recommended)

Prerequisites

  • Windows 10/11 with an NVIDIA GPU (RTX 3060+ recommended for real-time)
  • Python 3.10 or later: https://www.python.org/downloads/
  • Git: https://git-scm.com/download/win
  • NVIDIA CUDA 11.8 or 12.x drivers

Step 1: Run the setup script

scripts\vibevoice\setup-vibevoice.bat

This will:

  1. Create a Python virtual environment (vibevoice-env\)
  2. Install PyTorch with CUDA support
  3. Clone microsoft/VibeVoice into VibeVoice\
  4. Install the VibeVoice streaming TTS package

Step 2: Generate comparison samples

scripts\vibevoice\generate-voice-samples.bat

This generates one WAV file per voice in VibeVoice\voice-samples\ using the same comparison sentence so the voices are directly comparable. A README.md with a voice summary table is written alongside the WAV files.

Manual usage (from inside the VibeVoice repo)

REM Activate the venv first
vibevoice-env\Scripts\activate.bat
cd VibeVoice

REM Single voice
python demo\realtime_model_inference_from_file.py ^
    --model_path microsoft/VibeVoice-Realtime-0.5B ^
    --txt_path demo\text_examples\1p_vibevoice.txt ^
    --speaker_name Carter

REM Custom text (create a .txt file first)
echo Your custom narration text here. > my_script.txt
python demo\realtime_model_inference_from_file.py ^
    --model_path microsoft/VibeVoice-Realtime-0.5B ^
    --txt_path my_script.txt ^
    --speaker_name Emma

Output WAV files are saved to ./outputs/ by default.

Python script options

python generate-voice-samples.py [options]

  --model-path PATH    HF model ID or local path (default: microsoft/VibeVoice-Realtime-0.5B)
  --voices-dir PATH    Path to demo/voices/streaming_model
  --output-dir PATH    Where to save WAVs (default: ./voice-samples)
  --text "..."         Override the comparison sentence
  --all-languages      Include non-English voices (download required)
  --device cuda|mps|cpu  Override auto-detected device

Model notes

  • Model: VibeVoice-Realtime-0.5B (single-speaker streaming TTS)
  • Context: 8k tokens (~10 min audio)
  • Latency: ~300ms first audio on NVIDIA T4 or Apple M4 Pro
  • Multi-speaker: The multi-speaker TTS-1.5B model was removed from the repo in September 2025 due to misuse. Only Realtime-0.5B is currently available.
  • Watermark: Every output includes an audible AI disclaimer and an imperceptible provenance watermark.
