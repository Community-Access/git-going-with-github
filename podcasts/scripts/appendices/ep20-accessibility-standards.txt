[ALEX]
First, don't use ARIA if native HTML suffices. A is already a button - adding role="button" to a is only needed when HTML semantics cannot be used. Then, all interactive ARIA widgets must be keyboard operable. Adding role="button" means you must also handle Enter and Space keypresses in JavaScript. After that, aRIA only affects the accessibility tree. It does not add visual styling or behavior - it only changes what assistive technologies announce. Treat it like a recipe: do not add the next ingredient until the previous one is actually in the bowl.

[ALEX]
