Give us heading hierarchy in practice.

[ALEX]

Issue detail: H1 issue title; section headings for description, activity, and related blocks.
Pull request detail, Conversation tab: H1 PR title; structured headings for timeline sections.

How does layout shift across screen sizes?

[ALEX]
At full desktop width (1200px+), controls are most expanded and stable.
At tablet width (768-1199px), spacing compresses and some controls regroup.
At mobile width (below 768px), navigation condenses into toggles and stacked flows.

[ALEX]
Key point: landmark purpose remains consistent even when visual layout compresses.
